# Lexavra Gaming — Flutter Take-Home Assignment

A Flutter virtual gaming application prepared for **Lexavra Infinology Pvt Ltd**.

The application uses virtual **Game Coins** only. It contains no real-money payments, payment processing, or backend integration.

## Setup and Run

### Requirements

- Flutter SDK compatible with the project's Dart constraint: `^3.10.4`
- A configured Flutter device or emulator
- Java 17 for Android builds

The repository includes Android and iOS runner projects.

- Android configuration uses Java 17.
- iOS deployment target is iOS 13.0.

The project was verified with:

- Flutter 3.38.5
- Dart 3.10.4

### Run from a clean clone

```bash
flutter pub get
flutter run
